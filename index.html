Import from a CSV file

You must be signed in — imported rows go into your account only. Import each file once: importing the same file again will duplicate expenses and income. Daily gains are different — importing the same date again updates that day instead of duplicating it.

File formats (first row is the header)

Expenses — date,label,amount,category,kind
e.g. 2026-10-31,Gas (20th),69.45,Gas,expense — kind is expense or investment, date is YYYY-MM-DD, amount is dollars.

Income — date,amount,source,note,date_known
e.g. 2026-11-11,20.00,Not tracked,Past income — date not tracked,false — date_known is true or false.

Daily gains — date,amount,note,is_estimate
e.g. 2026-11-10,-63.78,,false — amount can be negative, is_estimate is true or false.

About Stack

Stack — build your stack of spending, income, and investing, all in one place.

Free, for a small group of friends and family (3–10 people). No charges, no paywall, no ads. Each user only sees their own data — Row Level Security is on for every table. Your data is stored in your own Supabase project, not with Stack.

Stack is free for a small group (3–10 people). No payment details are ever collected here. Supabase Free projects pause after about a week with too little database activity — data is kept and restored from the Supabase dashboard.
